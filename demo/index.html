ImagesViewer API 文档与完整演示

原生 JavaScript 图片查看器，支持虚拟列表、浏览器懒加载、手势拖拽与键盘快捷键。
不依赖 Vue / React / Angular，可在任何前端项目中直接使用。

共生成 1000 张测试图片 缩略图虚拟列表只渲染约 15 个 DOM 节点 浏览器原生懒加载，零手动缓存管理

快速入口

点击下方按钮直接打开不同场景的查看器。

示例 1：基础用法

传入图片对象数组，配置常用按钮和事件回调。

import ImagesViewer from '../src/index.js'

const viewer = new ImagesViewer({
  images: [
    {
      url: 'https://example.com/1.jpg',
      thumbnail: 'https://example.com/1-thumb.jpg',
      title: '示例 1'
    },
    {
      url: 'https://example.com/2.jpg',
      thumbnail: 'https://example.com/2-thumb.jpg',
      title: '示例 2'
    },
  ],
  backdrop: false,
  loop: true,
  buttons: {
    zoomIn: true,
    zoomOut: true,
    rotateLeft: true,
    rotateRight: true,
    reset: true,
    download: true,
    fullscreen: true,
    prev: true,
    next: true,
    close: true,
    topClose: true,
    thumbnails: true,
    info: true,
  },
  onChange: (data) => console.log('切换:', data.index),
  onImageError: (data) => console.warn('加载失败:', data.url),
})

示例 2：字符串数组

如果图片只有 URL，可以直接传入字符串数组。会自动使用 URL 作为缩略图，并生成默认标题。

const viewer = new ImagesViewer([
  'https://example.com/a.jpg',
  'https://example.com/b.jpg',
  'https://example.com/c.jpg',
])

示例 3：自定义属性映射

当后端返回的数据字段名与默认不符时，可通过 props 自定义映射。也支持函数映射。 

const viewer = new ImagesViewer({
  images: [
    {
      src: 'https://example.com/1.jpg',
      thumb: 'https://example.com/1t.jpg',
      name: '风景 1'
    },
    {
      src: 'https://example.com/2.jpg',
      thumb: 'https://example.com/2t.jpg',
      name: '风景 2'
    },
  ],
  props: {
    url: 'src',
    thumbnail: 'thumb',
    title: (item, index) => `${item.name} - 第 ${index + 1} 张`,
  },
})

示例 6：自定义信息面板与计数器

通过 onInfo 和 onCounter 完全自定义信息面板和计数器内容。

const viewer = new ImagesViewer({
  images: imageList,
  imageInfo: {
    visible: true,
    showName: true,
    showDimensions: true
  },
  onCounter: ({ index, total }) => `第 ${index + 1} / ${total} 张`,
  onInfo: ({ index, total, scale, rotation }) => {
    return `

  序号: ${index + 1} / ${total}

  缩放: ${(scale * 100).toFixed(0)}%

  旋转: ${rotation}°

`
  },
})

示例 8：错误处理与重试

开启 retryOnError 在图片加载失败时自动重试，并通过回调获取错误信息。

const viewer = new ImagesViewer({
  images: imageList,
  retryOnError: true,
  onImageError: ({ url, index }) => {
    console.error(`图片加载失败 [${index}]: ${url}`)
  },
})

示例 10：程序化控制

保留实例引用，通过 API 方法在外部控制查看器。

const viewer = new ImagesViewer({
  images: imageList,
  loop: true
})

// 2 秒后自动切换
setTimeout(() => viewer.next(), 2000)

// 5 秒后放大并旋转
setTimeout(() => {
  viewer.zoom(0.5)
  viewer.rotate(90)
  viewer.view(5)
}, 5000)

// 10 秒后关闭
setTimeout(() => viewer.hide(), 10000)

示例 11：错误图片 fallback

支持全局默认错误图和单图独立错误图。加载失败时先尝试单图 fallback，没有则使用全局 defaultFallbackImage。 

// 方式 A：全局默认错误图
const viewer = new ImagesViewer({
  images: imageList,
  defaultFallbackImage: 'https://example.com/default-error.jpg',
})

// 方式 B：单图独立错误图（覆盖全局）
const viewer = new ImagesViewer({
  images: [
    { url: 'https://a.jpg', fallback: 'https://a-fallback.jpg' },
    { url: 'https://b.jpg', fallback: 'https://b-fallback.jpg' },
  ],
  defaultFallbackImage: 'https://example.com/default-error.jpg',
})

示例 12：微前端生命周期

在 qiankun / micro-app / single-spa 等微前端框架中，子应用卸载时必须彻底销毁查看器，避免全局事件泄漏。 

// 子应用挂载时初始化
let viewer = null

export function mount() {
  viewer = new ImagesViewer({ images, loop: true })
}

// 子应用卸载时彻底销毁
export function unmount() {
  if (viewer) {
    viewer.hide()  // 触发完整销毁流程
    viewer = null
  }
}

// 销毁时会自动清理：
// - 所有 document / stage 事件监听
// - 所有 setTimeout（zoomTimer、retryTimer）
// - 所有图片（img lazy 属性交给浏览器释放）
// - 虚拟列表 DOM 与对象池
// - body.overflow 原始状态

示例 17：运行时切换显示

通过 toggleTitle()、toggleCounter()、toggleNavButtons() 在运行时动态切换各元素的显示状态。支持链式调用。 

const viewer = new ImagesViewer({ images: imageList })

// 隐藏标题
viewer.toggleTitle()

// 同时隐藏计数器和导航按钮
viewer.toggleCounter().toggleNavButtons()

// 全部恢复显示
viewer.toggleTitle().toggleCounter().toggleNavButtons()

示例 18：跳转到指定图片

构造选项

参数 类型 默认值 说明
images string[] | object[] [] 图片列表。字符串数组将自动补全为对象。
props object {url,title,thumbnail} 属性映射。值可为字符串或函数 (item, index) => value。
backdrop boolean false 点击遮罩或舞台背景关闭查看器。
minZoomRatio number 0.1 最小缩放倍率。
maxZoomRatio number 5 最大缩放倍率。
loop boolean true 首尾循环切换。
retryOnError boolean false 加载失败时自动重试（加时间戳防缓存，最多 3 次）。
defaultFallbackImage string '' 全局默认错误图片 URL。单图可设置 fallback 覆盖此值。
showThumbBar boolean true 是否显示底部缩略图栏。设为 false 可完全隐藏缩略图栏。
showTitle boolean true 是否显示图片标题。
showCounter boolean true 是否显示页码计数器（如 1 / 10）。
showNavButtons boolean true 是否显示左右导航箭头按钮。
itemClass string '' 全局缩略图项 CSS class。单图可设置 itemClass 覆盖此值。
activeItemClass string '' 全局选中缩略图项 CSS class。单图可设置 activeItemClass 覆盖此值。
errorClass string '' 全局图片加载失败时 CSS class。单图可设置 errorClass 覆盖此值。
buttons object 除 copy 外均为 true 控制各按钮显隐。见下方按钮配置。
customButtons [string, fn][] [] 自定义工具栏按钮。格式 [label, handler]，handler 中 this 指向 viewer 实例。
initialViewIndex number 0 初始打开的图片索引。
zIndex number 5000 查看器容器 z-index，控制层级。
imageInfo object {visible:false, showName:true, showDimensions:true} 信息面板配置。见下方。
i18n object 中文 国际化文案。见下方。
theme object 暗色主题 完整主题配置。见下方。
onShow fn({viewer,index,image,total}) null 查看器打开后触发。所有回调均带统一基础字段。
onClose fn({viewer,index,image,total}) null 查看器关闭后触发。
onChange fn({...,oldIndex,direction}) null 图片切换时触发。
onRotate fn({...,rotation}) null 旋转时触发。
onDrag fn({...,translateX,translateY}) null 拖拽时触发。
onZoom fn({...,scale}) null 缩放时触发。
onImageError fn({viewer,index,image,total,url}) null 主图加载失败时触发。
onInfo fn({viewer,index,image,total,scale,rotation}) null 返回 HTML 字符串以自定义信息面板内容。
onCounter fn({viewer,index,image,total}) null 返回字符串以自定义计数器内容。

实例方法

方法 参数 说明
zoom(delta) number 相对缩放，如 0.2 放大 20%，-0.2 缩小 20%。
rotate(deg) number 相对旋转，如 90 顺时针 90°，-90 逆时针 90°。
reset() — 重置缩放、旋转和位移。
zoomTo(ratio) number 缩放到绝对倍率，受 minZoomRatio / maxZoomRatio 约束。
rotateTo(degree) number 旋转到绝对角度（deg）。
move(x, y) number, number 相对位移，y 省略时取 x。
moveTo(x, y) number, number 移动到绝对位移，y 省略时取 x。
toggle() — 在 1（原始比例）与「适应窗口」倍率之间切换缩放。
view(index, animated) number, boolean 跳转到指定索引，animated 默认 true。
prev() — 切换到上一张。
next() — 切换到下一张。
toggleImageInfo() — 切换左上角信息面板显隐。
toggleThumbnails() — 切换底部缩略图栏显隐。
toggleTitle() — 切换图片标题显隐。支持链式调用。
toggleCounter() — 切换页码计数器显隐。支持链式调用。
toggleNavButtons() — 切换左右导航箭头显隐。支持链式调用。
toggleFullscreen() — 切换浏览器全屏模式。
tooltip() — 显示当前缩放百分比指示器（1.5 秒后自动隐藏）。
play() — 开始幻灯片自动播放，间隔由 interval 选项控制（默认 5000ms）。
stop() — 停止幻灯片自动播放。
update() — 重新读取 options.images 并刷新视图，用于动态增删 / 替换图片。
copyImage() — 复制当前图片到剪贴板（需浏览器支持）。返回 Promise。
downloadImage() — 触发当前图片下载（受跨域限制）。
hide() — 关闭查看器并销毁 DOM（所有方法均支持链式调用）。

键盘快捷键

按键 功能
← / → 上一张 / 下一张
Esc 关闭查看器
+ / = 放大
- / _ 缩小
0 重置缩放与旋转
f 切换全屏
i 切换信息面板
双击 重置变换
滚轮 缩放
拖拽 平移图片（任何缩放倍率下均可，允许越过边界 60px，松手自动回弹）

安装与使用

ESM 导入

import ImagesViewer from 'images-viewer-virtual'

new ImagesViewer({ images: imageList })

CDN / UMD

<script src="https://unpkg.com/images-viewer-virtual/dist/images-viewer.umd.js"></script>
<script>
  const viewer = new ImagesViewer({ images: imageList })
</script>

Vue 2 / Vue 3

// 不依赖 Vue，任何框架均可直接调用
methods: {
  openViewer() {
    new ImagesViewer({
      images: this.imageList,
      initialViewIndex: this.currentIndex
    })
  }
}

微前端（qiankun / micro-app / single-spa）

let viewer = null

export function mount() {
  viewer = new ImagesViewer({ images, loop: true })
}

export function unmount() {
  if (viewer) {
    viewer.hide()
    viewer = null
  }
}
